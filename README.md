## 📖 نظرة عامة
Trendora Shop هو متجر إلكتروني متكامل مبني بتقنيات حديثة، يقدم تجربة تسوق فريدة مع تحليلات متقدمة لتتبع سلوك المستخدم.

## ✨ المميزات

### 🛒 تجربة التسوق
- ✅ عرض المنتجات وتصنيفها
- ✅ عربة تسوق ذكية
- ✅ عملية دفع آمنة
- ✅ تتبع الطلبات
- ✅ نظام تقييم المنتجات

### 📊 التحليلات
- 🔍 Google Analytics متكامل
- 📈 تتبع سلوك المستخدم
- 📱 تحليلات في الوقت الفعلي
- 🎯 تقارير أداء متقدمة

### 🎨 واجهة المستخدم
- 🎪 تصميم responsive متكامل
- 🌙 وضع ليلي/نهاري
- 🔤 دعم متعدد اللغات
- ⚡ أداء عالي وسريع

## 🚀 التقنيات المستخدمة

### Frontend
- **React 18** - واجهة المستخدم
- **React Router** - التنقل بين الصفحات
- **Context API** - إدارة الحالة
- **Custom Hooks** - منطق قابل لإعادة الاستخدام

### الأدوات والتكاملات
- **Google Analytics** - تحليلات الموقع
- **ESLint** - ضمان جودة الكود
- **Vercel** - النشر والتوزيع

## 📦 التثبيت والتشغيل

### المتطلبات الأساسية
- Node.js (الإصدار 16 أو أعلى)
- npm أو yarn

### خطوات التشغيل
```bash
# استنساخ المشروع
git clone https://github.com/MohamedBerik/Trendora-shop.git

# الدخول للمجلد
cd Trendora-shop

# تثبيت الاعتمادات
npm install

# التشغيل في وضع التطوير
npm start

# بناء نسخة الإنتاج
npm run build
